# Before publishing

- [ ] Obtain/retain written confirmation that publication of this specific source is permitted.
- [ ] Review all source files for credentials, internal names, private URLs, and proprietary logic.
- [ ] Confirm no internal spreadsheets, logs, PDFs, or screenshots with customer data are present.
- [ ] Decide whether to add an open-source license.
- [ ] Test against an authorized sample workbook and current supplier websites.
- [ ] Record a short demonstration using synthetic data.
- [ ] Verify supplier terms and access rules before using automation.
